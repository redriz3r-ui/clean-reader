# Publication notes

Clean Reader is being preserved as a public-source candidate.

Current scope: FastAPI reader/gallery extraction, sanitization, Markdown/text export and a local moodboard. Source and tests are present.

Preparation still required: Publish app source and dependency files; exclude work, outputs and packaged .app bundles. Add a project-level license; bundled dependency licenses are not a license for this project. Demonstrate with synthetic or shareable content.
